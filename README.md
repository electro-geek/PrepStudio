# LearnForge

**AI-powered learning platform — from study plan to interview to published article.**

LearnForge takes a topic and a deadline, builds a personalized day-by-day study curriculum, generates deep reading material for each topic, conducts a voice AI interview when you're ready, and helps you publish polished articles about what you learned — all saved to your account.

---

## What It Does

### 1. Conversational Plan Creation
Open the app, tell it what you want to learn and how many days you have. A two-turn chat interface collects your topic and timeline, then calls Gemini to generate a full study plan: days broken down into specific topics, each day balanced to be completable in a realistic session.

### 2. Day-by-Day Study Plan
Your plan lives in your dashboard as a persistent card. Inside, a sidebar shows every day with a progress indicator. Each day contains multiple topics, displayed as clickable cards. Days you've finished are marked. The whole plan is saved to your account and available every time you log in.

### 3. Deep Topic Reading
Click any topic and you get a full article-quality explanation: rich text with headings, code examples, analogies, and practical walkthroughs — generated by Gemini and cached so the second load is instant. At the bottom of every topic you'll find three article ideas drawn from what you just read, and two action buttons.

### 4. Article Writing + AI Refinement
Click "Write Article" from any topic and you land on a two-panel editor. The left side is a plain text scratchpad — write messily, in short-hand, however you naturally think. Hit "Refine" and Gemini rewrites your notes into a publication-ready Markdown article with a proper title, intro, code blocks, and conclusion. You get two copy buttons: one for the full Markdown (for dev.to, Hashnode, a blog), and one formatted as a Twitter/X thread.

### 5. Voice AI Interview
Once you've worked through enough of your plan, the "Interview" button unlocks. The AI interviewer reads questions aloud using the browser's speech synthesis. You respond by speaking — your answer is transcribed in real time. After 8 questions covering everything you studied, Gemini evaluates each answer for accuracy, depth, and clarity. You receive a score out of 100 plus a breakdown of strengths and areas to improve.

### 6. Persistent User Accounts
Firebase Authentication handles login with Google or email/password. Every plan, every piece of generated content, every article, and every interview result is stored in PostgreSQL under your user account. Nothing is lost between sessions.

## Features at a Glance

- Chat-style plan creation (topic + number of days)
- AI-generated day-by-day curriculum breakdown
- Full reading content for each topic (lazy-generated, then cached)
- Article idea suggestions at the bottom of every topic
- Plain-text-to-polished-Markdown article refiner
- Twitter/X thread copy format
- Voice AI interview with Web Speech API (speak your answers)
- Numeric score + strengths/improvement feedback after interview
- Firebase auth with Google OAuth
- All data persisted per user in PostgreSQL

## Full User Flow

```
1. Sign Up / Log In
   └─> Firebase Auth (Google or email)

2. Dashboard
   └─> See all existing plans (or empty state)

3. Create New Plan  (/new)
   └─> Chat: "I want to learn Django"
   └─> Chat: "7 days"
   └─> Gemini generates structured plan (days + topic titles)
   └─> Plan saved to DB, redirect to Plan View

4. Plan View  (/plan/:id)
   └─> Sidebar: Day 1, Day 2, ..., Day 7
   └─> Click a day → see its topics
   └─> Click a topic → open Topic View

5. Topic View  (/plan/:id/day/:dayId/topic/:topicId)
   └─> Full content loaded (generated on first open, cached after)
   └─> Read and understand the material
   └─> Article ideas listed at bottom
   └─> Mark topic complete → updates day progress
   └─> Click "Write Article" → Article Editor

6. Article Editor  (/plan/:id/topic/:topicId/article)
   └─> Type rough notes in plain text
   └─> Click "Refine" → Gemini returns polished Markdown article
   └─> Copy full Markdown OR copy Twitter thread format

7. Interview  (/plan/:id/interview)
   └─> Only unlocked after majority of plan complete
   └─> AI reads 8 questions aloud (TTS)
   └─> User speaks answers (STT → transcribed text)
   └─> Gemini scores each answer (accuracy, depth, clarity)
   └─> Final score /100 + detailed feedback displayed
   └─> Can retake interview anytime
```

## Getting Started

### Prerequisites
- Node.js 20+
- Python 3.12+
- A Firebase project with Authentication enabled
- A Gemini API key from Google AI Studio
- A PostgreSQL database (Neon DB free tier works)

### Clone and Install

```bash
git clone https://github.com/yourname/learnforge
cd learnforge

# Frontend
cd frontend
npm install
cp .env.example .env.local
# Fill in Firebase config + API URL

# Backend
cd ../backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Fill in DATABASE_URL, GEMINI_API_KEY, Firebase Admin credentials
```

### Database Setup

```bash
cd backend
alembic upgrade head
```

### Run Locally

```bash
# Terminal 1 — Backend
cd backend && uvicorn app.main:app --reload --port 8000

# Terminal 2 — Frontend
cd frontend && npm run dev
```

Open `http://localhost:3000`.

## API Overview

All routes require `Authorization: Bearer <firebase_id_token>`.

| Method | Route | Description |
|---|---|---|
| POST | `/plans` | Create plan + trigger AI generation |
| GET | `/plans` | List user's plans |
| GET | `/plans/:id` | Full plan with days |
| PATCH | `/days/:id/complete` | Mark day complete |
| GET | `/topics/:id` | Full topic content (lazy gen) |
| PATCH | `/topics/:id/complete` | Mark topic complete |
| POST | `/articles` | Save raw article text |
| POST | `/articles/:id/refine` | Refine to Markdown via Gemini |
| POST | `/interviews` | Start interview |
| POST | `/interviews/:id/answer` | Submit answer, get next question |
| GET | `/interviews/:id` | Full interview + score |
